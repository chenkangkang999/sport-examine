# 数据库文件

| 文件                                      | 用途                                                               |
| ----------------------------------------- | ------------------------------------------------------------------ |
| `schema.sql`                              | MySQL 8 建表；使用 `CREATE TABLE IF NOT EXISTS`，不删除已有数据    |
| `migrations/20261112-hospital-labels.sql` | 已初始化课程库的医院展示文案更新，严格匹配旧默认值，不改写历史订单 |
| `reset.sql`                               | 主动重置课程库，执行前应确认库名并备份；正常启动无需执行           |

后端启动会执行资源目录中的同一份建表脚本。虚构医院、套餐、医生和用户等初始数据由 `server/.../config/DemoData.java` 写入，密码在写入时通过 BCrypt 哈希，因此没有明文密码 SQL 数据转储。

正常使用根目录启动脚本时，会创建项目独立数据库 `tijian` 和测试库 `tijian_test`。其他 MySQL 环境请先创建专用库和账号，再设置数据库连接环境变量。连接密码、真实数据目录和本机 SQL 备份均不应提交。

完整关系与字段说明见 [DATABASE.md](../docs/DATABASE.md)。
