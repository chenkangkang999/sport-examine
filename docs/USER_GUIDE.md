# 系统操作说明

## 1. 三种身份与入口

| 身份         | 访问地址                 | 现有账号 / 密码                            | 日常工作                                      |
| ------------ | ------------------------ | ------------------------------------------ | --------------------------------------------- |
| 用户         | `http://127.0.0.1:8081/` | `13800000001` / `Health123!`，也可自行注册 | 管理本人和家属、预约、查看订单与已归档报告    |
| 和平院区医生 | `http://127.0.0.1:8089/` | `D001` / `Doctor123!`                      | 查询云医院-和平院区的预约、填写检查结果并归档 |
| 建设院区医生 | 同上                     | `D002` / `Doctor123!`                      | 查询云医院-建设院区的预约并处理报告           |
| 系统管理员   | 同上                     | `admin` / `Admin123!`                      | 维护医院、检查项目、套餐、名额、医生账号等    |

用户端和管理端可以在同一浏览器分别登录、独立退出。医生登录页的“体检医生”和“系统管理员”按钮保留快捷填充功能，点击后还需点击“登录工作台”。用户登录页需要手动输入账号和密码，右侧眼睛按钮用于显示或隐藏密码。

## 2. 整体工作流程

```text
管理员准备医院、检查项目、套餐、套餐关联、日期名额和医生
                         ↓
用户注册 / 登录 → 选择本人或家属 → 医院 → 套餐 → 日期
                         ↓
                  核对信息并确认支付
                         ↓
                创建预约，状态为“未归档”
                         ↓
所属医院医生查询预约 → 填写检查结果 → 分项保存
                         ↓
                 添加并保存总检结论
                         ↓
                    核对后归档
                         ↓
     状态变为“已归档”，报告只读，用户可以查看完整报告
```

另有取消分支：预约日期之前、医生尚未保存检查结果时，用户可以取消预约；系统保留订单历史并恢复日期名额。已取消订单不能继续录入或归档。

## 3. 用户如何预约和查看报告

1. 登录用户端；新用户先注册，姓名、生日、性别与证件信息应对应。
2. 为家人预约时，在“我 → 家人健康档案”先添加家属。本人档案由注册资料生成。
3. 从首页“团检预约”进入，选择“本人预约”或“家属预约”，再选具体体检人。
4. 依次选择体检机构、适用套餐、开放且有剩余名额的日期。套餐的“详情”可以展开检查内容。
5. 在确认页核对姓名、日期、医院、地址、套餐和金额，勾选确认信息后点击“确认支付”。预约成功后可以查看订单。
6. “我 → 我的预约”查看预约状态、详情，或在允许时取消。
7. 医生归档后，进入“我 → 我的体检报告”或首页“我的健康报告 → 立即查看”，选择体检人并打开报告。“总检结论”查看异常与建议，“报告详情”查看各项结果和参考范围。

预约已经创建但医生尚未归档时，用户报告列表不会提前展示报告。每位体检人同一时间最多有一条未归档的有效预约。

## 4. 医生如何完成归档

1. 登录管理端。云医院-和平院区的预约使用 `D001`，云医院-建设院区的预约使用 `D002`。每位医生仅能操作所属医院的订单。
2. 在“体检客户查询”中填用户手机号或姓名，可结合套餐、体检日期、性别及归档状态筛选，再点击“查询”。“未归档”是日常录入的主要列表；“全部”表示不限制对应条件。
3. 找到订单后点击“编辑体检报告”，先核对左侧体检人、套餐和日期。
4. 在右侧各检查分组填写结果。数值项输入有效数字，系统按参考范围判断异常；描述类结果由医生填写并按实际情况标记异常。
5. **每填完一组，点击该组的保存按钮。** 仅填写但未保存的内容不能归档。
6. 在页面下方“总检结论”区域填写“总检结论项标题”和“总检结论项内容”，点击“添加”。结论会出现在表格中，可继续添加、更新或删除；至少要有一条已经保存的结论。
7. 确认全部必填检查结果已保存、没有遗漏后，点击红色归档按钮，在确认框点击“确认归档”。
8. 页面出现“已归档”提示并转为只读，用户端即可查看报告。返回查询页，将归档状态切为“已归档”可以再次查看。

**归档不成功时：** 按提示补齐必填结果、先保存修改，或添加总检结论。如果提示版本已变化，说明其他页面已先保存；重新加载最新报告并核对后再操作。已归档报告当前没有撤销归档或重新编辑入口。

## 5. 系统管理员如何操作

管理员登录后可在顶部菜单切换维护模块。新增一家医院供用户预约时，建议按以下顺序配置：

| 顺序 | 菜单     | 操作                                                                         |
| ---- | -------- | ---------------------------------------------------------------------------- |
| 1    | 医院信息 | 新增医院，填写名称、电话、地址、营业时间、采血截止及图片，保持启用           |
| 2    | 检查项目 | 新增检查项及结果明细，配置结果类型、单位、参考值、是否必填                   |
| 3    | 体检套餐 | 新增套餐，填写价格与适用性别，并选择包含的检查项目                           |
| 4    | 医院套餐 | 选择医院，勾选该院提供的套餐并保存；未关联的套餐不会出现在该院预约页         |
| 5    | 预约名额 | 选择医院、日期区间、开放星期和每日容量并保存；无排班或容量为零的日期不可预约 |
| 6    | 医生账号 | 新增医生工号、姓名、初始密码、角色及所属医院，保持启用                       |

已有资料可点击“编辑”调整。历史订单引用的资料使用“停用”保留；后续预约读取新配置，既有订单保留预约时的价格和检查内容。每日容量不能调低到已占用名额以下。

管理员可以查看各医院预约及报告；日常结果录入和归档通常由所属医院医生完成。医生账号无法进入管理员基础资料菜单，后端也会校验权限。

## 6. 本次文案和历史机构信息修正

登录页、确认页、订单页已按当前要求简化显示，交易处理仍沿用本地课程模拟流程，没有接入真实扣款服务。

早期订单曾保存旧默认医院文案，因此与后来修改的医院选择页不一致。迁移仅修正两所默认机构旧名称、旧地址的显示文字，不修改订单金额、个人资料、检查结果，也不把管理员后续修改的所有医院资料实时覆盖到历史订单。

2026年11月15日起，两所默认机构统一命名为“云医院-和平院区”和“云医院-建设院区”，对应医生仍为 D001 和 D002。医院基础资料、原默认名称的历史订单与报告、站内通知同步迁移；初始化使用新院区名。管理端登录页及所有医生、管理员共用页头统一为“体检报告管理系统”，移除“Neusoft 东软”字样。

## 7. 新增功能如何使用

- **阅读字号：** 点击顶栏或登录页右上角的 Aa 切换大字模式，再次点击恢复标准字号。选择保存在当前设备。个人中心在标准字号下继续一屏显示。
- **页面背景：** 用户端内容页共用柔和医疗底图，手机与电脑中间应用区域同步显示，电脑两侧仍为原灰色。卡片、输入框、导航及弹窗保持不透明白底，图片不透进内容区域；彩色登录页、个人顶部和成功页渐变保留，报告打印仍为白纸版。
- **预约进度与对比：** 预约页顶部显示五个步骤，可点击已完成步骤返回。套餐页选择 2–3 个套餐后打开对比，查看价格、适用人群和检查项目差异，再直接预约所选套餐。
- **体检前指南：** 预约成功和订单详情显示机构准备事项、到院流程及联系方式。管理员进入“医院信息”，点击对应医院的“体检指南”进行维护；具体检查准备以机构提供的信息为准。
- **我的体检与消息：** 首页“我的体检”展示当前或最近预约及最新报告。顶栏信封进入消息中心，可筛选未读、标记单条或全部已读；点击消息进入订单或报告，已读状态刷新后保留。
- **报告区间与趋势：** 在报告详情查看数值的参考区间位置；点击“历次指标”后选择体检人和指标，查看真实的历次归档记录。仅有一份报告时显示单次结果，不生成虚构趋势；下方记录可打开原报告。
- **打印报告：** 在已归档报告顶部点击“打印 / 保存 PDF”，浏览器打印窗口选择打印机或“另存为 PDF”。输出包含完整检查结果和总检结论，不受当前屏幕标签影响。
- **资讯与医生：** 首页资讯和医生卡片可打开详情。科普页面附参考来源及相关阅读，医生介绍为课程资料，实际安排仍需联系机构。
- **医生待办：** “体检客户查询”顶部汇总今日预约、待录入、录入中／待归档及已归档，点击卡片切换对应筛选。录入中不表示已经满足归档条件，仍须补齐必填项和总检结论。
- **管理员统计：** 点击“数据统计”，选择医院及日期区间，查看每日预约、名额使用率、热门套餐和归档情况。日期按体检日期统计；归档率不计已取消订单。
