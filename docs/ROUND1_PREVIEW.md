# 第一轮改进记录

本文保留第一轮改进的范围与体验方法，属于开发历史记录；当前版本的完整内容见 [全部功能与使用说明](ALL_IMPROVEMENTS_PREVIEW.md) 和 [更新记录](../CHANGELOG.md)。第一轮保留原有主要页面、图片资源、用户端窄屏布局、医生端蓝灰色工作区及业务流程。

## 本轮增加与调整

| 内容               | 可以看到的变化                                                                  | 如何体验                                                             |
| ------------------ | ------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 视觉统一           | 统一青绿配色、表单边框与焦点、卡片圆角和间距；保留密码眼睛按钮和现有字号层级    | 对照登录、首页、个人中心、医院与套餐页面                             |
| 五步预约进度       | 显示体检人、医院、套餐、日期、确认五步及当前位置，完成的步骤可返回              | 从首页“团检预约”开始；不能跳过前置选择                               |
| 套餐对比           | 选 2–3 个套餐，比较价格、适用人群、检查项目与明细；可从对比选择套餐继续预约     | 选择体检人与医院后，在套餐页加入对比并打开对比面板                   |
| 报告打印与保存 PDF | A4 白底报告包含完整检查结果、参考范围、异常和总检结论；不受屏幕当前报告标签影响 | 打开已归档报告，点击打印入口，在系统打印窗口选择打印机或“另存为 PDF” |
| 健康资讯详情       | 首页两条资讯可打开完整科普文章，包含分节正文和权威来源链接，取消虚构评论数量    | 首页底部“健康咨询”区域点击文章                                       |

第一轮反馈曾要求撤销新增浅色医疗背景，保留其他改进。11月15日的最终界面规则进一步明确为：用户端内容页使用医疗图片作为底图，内容卡片、表单、导航及弹窗保持不透明白底；彩色登录、个人顶部、成功页渐变及管理端蓝灰背景保留，电脑两侧灰色区域不变。套餐信息读取当前医院接口，报告使用后端已经归档的数据，不接入真实支付。

## 本地体验入口

- 用户端：`http://127.0.0.1:8081/`
- 医生／管理端：`http://127.0.0.1:8089/`
- 用户账号：`13800000001` / `Health123!`
- 医生账号：`D001` / `Doctor123!`
- 管理员账号：`admin` / `Admin123!`

体验套餐对比时无需真正下单；从面板选择套餐只进入日期选择步骤。打印入口调用浏览器打印能力，用户仍需在打印窗口选择保存位置。

## 后续完善

第一轮五项改进继续保留。后续补齐了大字模式、体检前指南、首页体检卡片、医生介绍、报告区间及趋势、消息中心、医生待办和管理员统计。功能入口见 [全部功能与使用说明](ALL_IMPROVEMENTS_PREVIEW.md)；原有家属档案、预约名额、结果保存、版本冲突、归档和权限校验继续保留。

源码入口见 [前端导读](FRONTEND_GUIDE.md)，原系统操作见 [用户、医生及管理员操作说明](USER_GUIDE.md)。
