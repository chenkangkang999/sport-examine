# 前端验收与课堂展示清单

本清单依据《东软体检项目系统-实践手册(6)》第 4–7 页原型和当前 Vue 实现编写，用于修改后的人工复验。未勾选框是待逐项确认的操作清单，不代表已经执行或通过。既有验证情况见[验证记录](VALIDATION.md)，源码位置见[前端开发导读](FRONTEND_GUIDE.md)。

## 1. 准备

- [ ] 按[项目说明](../README.md)启动 MySQL、后端、用户端 8081 和管理端 8089；确认登录页能打开，接口可用。
- [ ] 准备课程测试用户、可预约的本人 / 家属档案以及医生和管理员账号，使用虚构个人资料。
- [ ] 准备未来开放日期；没有余量时先由管理员检查名额配置。
- [ ] 用约 390 × 844 的手机视口检查用户端，再用约 1440 × 1000 的电脑窗口检查用户端居中布局和医生端表格。
- [ ] 打开浏览器控制台与网络面板，检查操作时有无页面异常、失败请求或图片加载错误。

## 3. 完整业务演示

1. [ ] 在注册页创建课程测试账号并进入首页；退出后用同一账号重新登录。
2. [ ] 进入“家人健康档案”，新增家属，再在预约页选择家属。
3. [ ] 依次选择医院、展开并选择套餐、选择有余量的未来日期。
4. [ ] 核对体检人、医院、日期和金额，勾选核对项后点“确认支付”；提交时按钮禁用，成功后可查看订单。
5. [ ] 用所属医院医生登录管理端，通过手机号 / 姓名查到预约，进入报告编辑。
6. [ ] 按检查项填写合法结果并分项保存；填写一项超出参考值的数值，保存后出现异常标志。描述项目可由医生标记异常。
7. [ ] 添加总检结论；尝试更新、清空表单、删除测试结论，最终保留至少一条完整结论。
8. [ ] 确认全部必填结果已保存后归档，归档后编辑与再次保存受限。
9. [ ] 用户进入“我的体检报告”，按家属筛选并打开新报告；核对异常、结论、建议和明细与医生保存内容一致。

## 4. 边界与反馈

- [ ] 表单：手机号格式、两次密码不一致、必填项缺失时有清晰提示，错误后仍能修改重试。
- [ ] 跳转：新标签页直接访问确认订单路由但没有草稿时，会提示并返回预约步骤。
- [ ] 刷新：选完医院 / 套餐后刷新同一标签页，草稿仍在；更换前面的体检人 / 医院，失效的后续选择被清除。
- [ ] 空数据：无预约、无报告、无家属时有说明和后续入口，页面不留白。
- [ ] 请求失败：后端暂不可达时显示错误或重试入口，恢复后可重新加载。
- [ ] 未登录：访问需登录页转到登录页，重新登录后可继续进入目标页面。
- [ ] 取消：另建未来且未录入结果的预约，取消后保留历史，相应日期余量恢复；当日或开始录入后的预约不能取消。
- [ ] 版本冲突：两个独立浏览器会话打开同一未归档报告，先后保存同一版本；后提交者收到冲突提示，可以重新加载。
- [ ] 历史资料：管理员修改医院或套餐后，旧订单 / 报告保留创建时快照，新预约使用更新资料。
- [ ] 保留入口：未接入的问诊、商城、评估等入口会说明当前范围，不能把展示入口计作已接通外部服务。

## 5. 构建与已有自动化

在仓库根目录分别构建两端：

```powershell
npm --prefix user-web run build
npm --prefix manage-web run build
```

构建成功后仍需打开浏览器检查布局；构建不验证真实按钮操作和业务数据。运行下面的浏览器测试前，需要已启动两端与后端，并安装根目录测试依赖及本机 Edge：

```powershell
npm ci
npm run test:e2e
```

现有 [`tests/browser/workflow.spec.js`](../tests/browser/workflow.spec.js) 包含三条流程：家属预约 → 医生保存 / 归档 → 用户报告；管理员模块加载与手机登录布局；个人资料 / 密码修改与重新登录。截图、失败跟踪和 HTML 报告在 `output/` 生成。测试创建带测试名称的虚构课程数据，不清空已有业务库。

并发、越权、CSRF、名额恢复和历史快照不能只凭页面外观判断；接口和数据库复验方法见[测试说明](TESTING.md)。

## 6. 课堂讲解顺序

先展示首页、评估滚动和个人中心菜单，再走“家属档案 → 预约五步 → 成功 / 订单”流程，随后切到医生端录入归档，最后回到用户端查看双标签报告。各段同时指出对应 Vue 文件、表单绑定和请求封装位置。

补充展示管理员配置如何改变医院、套餐或余量；说明数据由后端提供，刷新和重启后可以再次查询。支付按课程模拟交易展示，报告使用虚构检查结果。截图用于记录页面效果，验收以实际操作和接口结果为准。
